## bioSite — The World Through Sierra's Eyes

A three-page biographical website about Sierra, created for **bioSite: Development** in CSD 340. The design follows the Atomic Design planning from Module 5.2 and uses one shared stylesheet.

### Pages
- `index.html` — landing page with introduction and milestones
- `about.html` — biography, education, and professional experience
- `hobbies.html` — sports, culture, and travel
- `styles.css` — shared site design, atoms, and responsive layout
- `images/` — local website photographs

### Running locally
Open `index.html` in a browser. Navigation links work locally or when deployed to GitHub Pages.

### Image notes
Photographs provided for Sierra's bioSite project. Confirm permission from the rights holders before publishing photographs taken by others. Smithsonian building image is the Smithsonian Institution Building, not the Freedom Wall.
